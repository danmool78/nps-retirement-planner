# 부부 노후자금 통합 시뮬레이터

국민연금·교직원연금·공무원연금·주택연금·기초연금·추납·물가상승률·기대수명을 통합하여
부부의 은퇴 후 현금흐름을 **월 단위로 시뮬레이션**하고, 여러 전략 조합 중 최적안을 찾아
시각화하는 웹앱입니다.

**서버 없이 브라우저에서 계산합니다.** [stlite](https://github.com/whitphx/stlite)(Pyodide·WebAssembly)로
Streamlit 앱을 사용자 브라우저 안에서 실행하므로, 입력한 정보가 서버로 전송되지 않고
정적 호스팅(GitHub Pages)만으로 배포됩니다.

## 주요 기능
- 국민연금 조기/연기수령, 추납, 직역연금(교직원·공무원) 반영
- 주택연금 개시나이별 월지급액(HF 종신·정액형, 부부 중 연소자 기준)
- 기초연금 소득인정액 자동 판정(부부/단독 선정기준액), 연금소득세 차감
- **건강보험 피부양자 판정**: 연소득 2,000만원·재산 요건, 탈락 시 지역가입자 보험료(소득분·재산분·장기요양)
- **개인·퇴직연금(IRP·연금저축)**: 균등 수령, 1,500만원 기준 분리과세
- **나이별 생활비 변화**: 75세·85세부터 생활비 비율, 후기 의료·간병비
- **부부 / 1인 가구** 모드
- 물가·투자수익·변동성(몬테카를로)·기대수명을 반영한 월 단위 현금흐름
- **3가지 성향별 추천**: 안정형 · 총수령액 극대화형 · 상속중시형
- **한눈에 보는 결론**(쉬운 문장 요약)과 **'만약에'** 분석(생활비·은퇴나이·자산·수익률·물가·수명·집값·간병비)
- **시나리오 비교**: 결과를 이름 붙여 저장하고 나란히 비교·불러오기
- **입력값 기억·공유 링크**: 입력이 주소(URL)에 저장되어 새로고침·공유 시 그대로 열림
- 그래프 10종, 모바일 화면 대응, HTML(PDF 저장용) 리포트 / CSV / Excel 내보내기
- **홈 화면에 추가(PWA)**: 앱처럼 실행, 재방문 시 캐시로 빠르게 열리고 오프라인에서도 동작

## 제도 파라미터 자동 업데이트
보험료율·기준소득월액 상한·기초연금액·선정기준액·주택연금 상한 등은 `policy.json` 에
**시행일별 이력**으로 관리합니다.

- 앱은 접속 시점의 날짜에 맞는 값을 자동으로 고릅니다. 이미 확정된 미래 값(예: 보험료율
  2027년 10% … 2033년 13%)은 시행일이 되면 자동 적용됩니다.
- `policy.json` 만 고쳐 `main` 에 push 하면 다음 접속부터 모든 사용자에게 반영됩니다.
- GitHub Actions(`policy-check.yml`)가 매월 1·15일 점검해, 정기 갱신 시기(매년 1월 기초연금,
  매년 7월 기준소득월액 등)가 지났는데 새 값이 없으면 **'제도 파라미터 갱신 필요' 이슈**를 올립니다.
- 로컬 점검: `python scripts/check_policy.py`

## 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정(최초 1회).
2. `main` 에 push 하면 `pages.yml` 이 `index.html` 과 앱 파일을 배포합니다.

처음 접속 시 계산 엔진(Pyodide)을 내려받느라 10~30초 걸리고, 이후에는 브라우저 캐시로 빨라집니다.

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py          # 일반 Streamlit 으로 개발·확인
python -m http.server 8000    # 또는 브라우저 계산 버전: http://localhost:8000/index.html
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | stlite 진입점(브라우저에서 앱 실행) |
| `app.py` | Streamlit UI |
| `scenarios.py` | 시나리오 저장·비교 |
| `manifest.webmanifest` · `sw.js` · `icons/` | 홈 화면 추가(PWA)·오프라인 캐시 |
| `ui.py` | SVG 아이콘·공통 CSS·카드 컴포넌트 |
| `policy.json` / `policy.py` | 시행일별 제도 파라미터와 자동 선택 로직 |
| `config.py` | 제도 파라미터·사용자 입력 정의(대체 기본값) |
| `nps.py` · `teacher_pension.py` · `gov_pension.py` · `pension.py` | 공적연금 계산 |
| `housing_pension.py` | 주택연금 계산 |
| `cashflow.py` | 월 단위 현금흐름 시뮬레이션 |
| `optimizer.py` | 조합 전수평가·점수화·파레토·민감도 |
| `montecarlo.py` | 투자 변동성 스트레스 |
| `visualization.py` | plotly 그래프 |
| `export.py` | HTML/CSV/Excel 내보내기 |
| `scripts/check_policy.py` | 제도 파라미터 점검 |

## 주의
본 도구의 연금·주택연금 금액은 **근사 계산**이며, 실제 수급액은 국민연금공단·한국주택금융공사·
복지로의 공식 계산기 결과와 다를 수 있습니다. 제도 기준은 화면에서 조정할 수 있습니다.
